# swole test: configless deterministic Rust test runner

## Goal

`swole test` (`cargo swole test`) is a configless Rust test runner over stock `libtest` binaries for `moq`, `rind`, and `rust2` that replaces `cargo nextest` and `rust2-watchdog`: it builds once with fused `clippy-driver` and `CARGO_BUILD_WARNINGS=deny`, runs test binaries in parallel using sharded `--test-threads=1` batches bounded by `--timeout`, chains Cargo target runners (`simctl`, `sde`, `qemu`, `wasmtime`, `adb`) and wraps `cross`, enforces a hermetic Linux sandbox and strict deterministic RNG/clock/sleep-abort preload by default, and shares content-addressed test results across hosts over Tailscale via `mbx-cache`.

Non-goals: per-repo config files (`.config/nextest.toml`, `swole.toml`); adding test harness code to `crates/swole` (which stays a minimal benchmark `[dev-dependencies]` crate); moving benchmark `preload.so` fingerprints; delaying `swole` `m0` (`0.1.0` publish and CodSpeed removal); building a `ptrace`/hypervisor syscall emulator; or duplicating `quest gate` or `mbx`'s host-wide CPU scheduler.

## Plan

Decided 2026-11-27 (maintainer, `/quest-plan` in `kixel-ai/rust2`, replacing [kixel-ai/rust2#1079](https://github.com/kixel-ai/rust2/pull/1079) and `rust2`'s `quest/m1/test-watchdog.md`):

- ✅ Goal: full `swole test` scope (parallel sharded runner, fused `clippy-driver`, hermetic sandbox, strict time/RNG preload, and cross-host `mbx-cache` test caching) in `m1` so `m0` (`0.1.0` publish and CodSpeed removal) is not delayed (rejected: narrower runner + batching + clippy only; drop).
- ✅ Config: strictly configless via CLI flags and opinionated defaults (`--timeout` default `60s`, zero retries, immediate + final failure output, skipping benches), ignoring `.config/nextest.toml` (rejected: auto-reading `.config/nextest.toml`; adding a new `swole.toml`). Auditing all six `.config/nextest.toml` files in `moq`, `rind`, and `rust2` showed every active setting maps to `--timeout`, `--jobs`, or hardcoded defaults.
- ✅ Execution: sharded `--test-threads=1` batches across parallel binaries (1 process per small binary, split large binaries into parallel `--exact` / module-prefix batches, resume remaining tests after a crash or timeout, solo-retry batch failures to flag shared-state leaks) (rejected: multi-threaded in-process per binary with 60 s watchdog; process-per-test on native with batching only on emulated rows).
- ✅ Clippy fusion: `RUSTC_WORKSPACE_WRAPPER=clippy-driver` and `CARGO_BUILD_WARNINGS=deny` on by default, with `--no-clippy` and `--allow-warnings` to opt out, keeping local and CI `mbx` compile cache keys identical (rejected: opt-in `--clippy`; warn-only by default).
- ✅ Determinism and sandboxing: strict Linux sandbox (`CLONE_NEWUSER | CLONE_NEWNET | CLONE_NEWIPC`, ephemeral `TMPDIR`, Landlock read-only workspace, scrubbed env) and deterministic RNG + virtual clock preload on by default on day one (rejected: virtual/poisoned time opt-in first; all sandboxing and time shimming opt-in).
- ✅ Sleep and timeout enforcement: hard-abort immediately on `nanosleep`/`clock_nanosleep > 0` and `timerfd_settime`/`timer_settime`, and abort on `epoll_wait`/`epoll_pwait`/`poll`/`pthread_cond_timedwait`/`pthread_cond_clockwait`/`SYS_FUTEX` when a timeout actually expires (`ready == 0` or `ETIMEDOUT`) (rejected: virtual fast-forward sleeps by default; real-time waits by default; abort on any non-zero timeout passed to `epoll_wait`/`poll`/condvar/futex). `#[tokio::test(start_paused = true)]` and fast loopback I/O wrapped in a safety `tokio::time::timeout` pass cleanly, while un-paused `tokio::time::sleep` and wall-clock timeout waits fail loudly.
- ✅ Host-dirty and real-clock opt-out: global invocation flags (`--no-sandbox`, `--real-time`, `--no-cache`) plus auto-disabling Linux sandbox/preload on foreign runners and non-Linux hosts (rejected: filter-scoped opt-out flags). Non-hermetic runs never write to the test cache.
- ✅ Cross-host caching: v1 requirement, speaking `mbx-cache` v1 `task` action results and `/v1/action-manifests` over Tailscale (`MBX_REMOTE_URL`, `MBX_REMOTE_TOKEN_FILE`, `MBX_REMOTE_NAMESPACE`) plus a local disk cache, with workspace fixture reads auto-traced by the test preload (rejected: local-only cache first; diff-scoped selection only; binary-only cache skipping fixture readers; dedicated `swole` HTTP cache server).
- ✅ Emulated and device targets: chain Cargo's `target.<triple>.runner` (`simctl`, `sde`, `qemu`, `wasmtime`, `adb`) and wrap `cross` with PID-1 signal forwarding (rejected: native Linux/macOS/Windows only).
- ✅ `rust2` watchdog handoff: close [kixel-ai/rust2#1079](https://github.com/kixel-ai/rust2/pull/1079) now and delete `rust2`'s `quest/m1/test-watchdog.md` (rejected: keeping `#1079` open as a reference draft; shipping `rust2-watchdog` temporarily). Commit `690109f` in `#1079` remains in git history as reference for libtest output parsing and `simctl`/`cross --init` process-group kills.
